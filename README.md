# Open Plus presentations

Две эталонные HTML-колоды и skills для AI-агента, чтобы собирать аналогичные презентации на новых данных.

## Презентации

| Файл | Жанр |
|---|---|
| `AI Практикум_Д.Драпеза.html` | Практикум: от задачи к ассистенту и своему навыку |
| `Фабрика будущего — Open Plus день 1.html` | Keynote: фабрика будущего, кейсы и паттерны |

Открывать в браузере. Навигация: стрелки / кнопки, overview, заметки ведущего.

## Skills для агента

| Skill | Когда использовать |
|---|---|
| [`skills/open-plus-ai-practicum/SKILL.md`](skills/open-plus-ai-practicum/SKILL.md) | Новый воркшоп/практикум в стиле AI Практикума |
| [`skills/open-plus-factory-future/SKILL.md`](skills/open-plus-factory-future/SKILL.md) | Новый доклад в стиле «Фабрика будущего» |

Агенту: прочитать нужный `SKILL.md`, взять соответствующий HTML как оболочку (CSS/JS), заменить слайды и контент по брифу пользователя.
